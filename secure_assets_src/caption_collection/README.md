# NexusCut Caption Blueprint Collection

Ten editable JSON blueprints covering high-impact, educational, gaming, clean corporate, vlog, and retro caption treatments.

## Included

- 10 JSON style blueprints
- Font, sizing, weight, color, stroke, shadow, highlight, and animation values

## Use in NexusCut

Open a JSON blueprint in any text editor. In NexusCut, create or select a caption and reproduce the listed values in the caption properties. These files are design blueprints; NexusCut does not currently import caption-style JSON files automatically.
