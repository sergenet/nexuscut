# NexusCut High-Impact Caption Blueprint

This download contains an editable JSON blueprint for recreating the High-Impact caption look in NexusCut or another editor.

## Included

- `High_Impact_Style.json`
- Font, color, stroke, shadow, highlight, and animation settings

## Use in NexusCut

Open the editor, create or select a caption, and reproduce the values from the JSON file in the caption properties. NexusCut does not currently import caption-style JSON files automatically.

The style is an original NexusCut blueprint. It is not affiliated with or endorsed by any individual creator.
