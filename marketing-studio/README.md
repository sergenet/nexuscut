# NexusCut Marketing Studio

Internal marketing workspace for planning, writing, organizing, and approving social-media content for NexusCut.

## Features
- **Campaign Briefs**: Create and manage campaign templates.
- **Content Generator**: Generate a 30-day posting calendar across 5 platforms based on campaign briefs.
- **Content Library**: View, edit, duplicate, and manage the status of all generated drafts.
- **Calendar View**: See your upcoming schedule and export it to CSV.
- **Local Storage**: All data is stored locally in the browser. No database, authentication, or API keys are required for this version.

## Local Startup Instructions

1. Ensure you have Node.js installed (v18+ recommended).
2. Install the project dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:3000`.

*Note: Since the app uses browser local storage, your data will persist on the local machine/browser you are using.*
